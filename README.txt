PUBLISH FOR FREE WITH GITHUB PAGES
1. Create/sign in to a free GitHub account: https://github.com/
2. Create a PUBLIC repository named exactly: sunyojimbo.github.io
3. Upload index.html, style.css and cover.jpg into the repository root.
4. Open repository Settings -> Pages. Select Deploy from a branch, choose main and /(root), then Save.
5. Your site address will be https://sunyojimbo.github.io/ once publishing finishes.

No hosting fee and no paid domain required. A custom .ma domain is not free; use the GitHub address to keep the whole setup free.
